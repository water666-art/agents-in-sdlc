入门工作坊通过引导式练习介绍 GitHub Copilot，无需现有应用或详细开发场景。每个工作坊都从基础开始，在实际操作中介绍产品，并带你完成完整工作流。

每个工作坊都从空文件夹开始构建同一个太空问答。选择想要学习的工具，也可以完成多个工作坊来比较不同工具的使用方式。

> [!NOTE]
> 本工作坊由 [James Montemagno][james] 创建，改编自 [First Steps with GitHub Copilot][source-lab]，原内容采用 [MIT 许可证][source-license]。

## 工作坊

### [GitHub Copilot 应用入门][copilot-app]

从空文件夹开始构建色彩鲜明的太空问答，并完成开发循环：创建、改进、测试、记录项目说明、发布、规划工作、实现问题、评审并合并拉取请求、自动执行重复工作，以及探索 Canvas 扩展。

### [GitHub Copilot CLI 入门][copilot-cli]

学习以终端为核心的工作流：在 Git 写入任何内容之前构建项目并检查差异，在工作树中并行运行会话，先规划再编辑，管理上下文，然后不离开 shell 即可创建、合并和委派工作。

### [Visual Studio Code 入门][vscode]

使用编辑器工作流：在工作区中构建项目，在集成浏览器中改进界面，检查上下文，在 Git 写入之前测试，并使用 GitHub 工具在 VS Code 中处理问题、拉取请求和云会话。
