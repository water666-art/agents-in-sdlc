使用真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在软件开发生命周期中的应用。通过迭代规划更改、编写代码、测试行为、评审拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为桌游众筹平台注入开发者主题。团队的待办事项已作为 GitHub 问题创建，你可以直接开始处理。其中既有筛选和分页等功能，也有无障碍和编码规范等质量改进任务。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合自己的开发环境。每个工作坊都有独立的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能代理助手。练习 Plan 和 Autopilot 模式、说明文件、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot 应用][app]

在桌面应用中运行并行代理会话、切换会话模式、协作使用 Canvas，并管理 GitHub 问题和拉取请求。

### [GitHub Copilot 云代理][cloud]

将 GitHub 问题分配给异步代理，引导其工作、监控进度，并评审其创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
