根据想要学习的内容和探索深度选择工作坊。**入门**通过引导式练习介绍 GitHub Copilot；**真实开发场景**使用完整应用和团队待办列表，帮助你练习面向生产环境的工作流。

## 入门

通过有重点的引导式体验了解 GitHub Copilot 产品的主要功能，无需现有代码库。

### [GitHub Copilot 应用入门][first-steps-app]

从空文件夹开始构建太空问答，将其发布到 GitHub、实现一个问题、完成 Copilot 代码评审、安排自动化任务，并探索 Canvas 工作流。

### [GitHub Copilot CLI 入门][first-steps-cli]

在终端中构建同一个太空问答，检查差异，在工作树中运行并行会话，先规划再编辑，并在不离开 shell 的情况下创建、合并和委派拉取请求。

### [Visual Studio Code 入门][first-steps-vscode]

在 VS Code 中构建太空问答，在集成浏览器中测试，通过源代码管理发布，使用 GitHub 工具处理问题和拉取请求，并将工作交接给云会话。

## 真实开发场景

使用 Tailspin Toys 应用和待办列表，在逼真的软件开发生命周期中练习 GitHub Copilot。选择工作环境，然后规划、构建、测试、评审并交付有意义的更改。

### [浏览真实开发场景工作坊][real-world-development]

选择 GitHub Copilot CLI、GitHub Copilot 应用、GitHub Copilot 云代理或 Visual Studio Code。

> [!CAUTION]
> GitHub Copilot 采用概率式而非确定式生成，因此实际更改的代码和文件可能与示例不同。出现细微差异是正常的。
>
> 如果在讲师带领的工作坊中遇到故障或运行异常，请向导师寻求帮助。
