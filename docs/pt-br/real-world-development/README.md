Explore o GitHub Copilot ao longo do ciclo de desenvolvimento de software com cenários realistas, uma aplicação completa e um backlog compartilhado. Você trabalhará de forma iterativa para planejar mudanças, criar código, testar o comportamento, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é uma nova pessoa desenvolvedora na Tailspin Toys, uma empresa fictícia de financiamento coletivo para jogos de tabuleiro com uma temática voltada a desenvolvedores. O backlog da equipe já está organizado em issues do GitHub, prontas para serem escolhidas. Ele inclui funcionalidades como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de programação.

## Escolha seu ambiente

O GitHub Copilot acompanha você no ambiente em que trabalha. Escolha aquele que combina com a forma como você quer desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente com agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, MCP do Playwright, Agent Merge e comandos de barra úteis.

### [Aplicativo GitHub Copilot][app]

Execute sessões paralelas de agentes, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
