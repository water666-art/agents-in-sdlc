ここまでの演習で、ユーザーエクスペリエンスの改善や機能追加を目的とした 3 つのタスクを Copilot cloud agent に依頼しました。cloud agent は非同期かつ自律的に動作するように設計されていますが、タスクを監視することも重要です。

cloud agent に割り当てたタスクを管理するには、GitHub.com の[エージェントページ][agents-page]など、さまざまなツールを利用できます。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。実行された操作を調べたり、進行中のセッションに追加の指示を与えたりできます。

この演習では、次のことを行います。

- エージェントページで cloud agent のタスクを監視します。
- 進行中のセッションに追加の機能を依頼し、方向付けます。

## シナリオ

ハイコントラストモードを作成するようエージェントに割り当てた後、チームはライトモードも追加するのにちょうどよい機会だと気付きました。サイトのスタイル更新と切り替え機能の追加をすでに進めているため、ライトモードも含めるのが合理的です。エージェントに追加の指示を与え、ハイコントラストに加えてライトモードも追加するようにします。

## Copilot cloud agent のタスクを確認する

Copilot cloud agent に割り当てたすべてのタスクの現在の状態を確認します。

1. [Copilot エージェントページ](https://github.com/copilot/agents)を開きます。
2. メインペインと左側のペインにあるタスク一覧を確認します。Copilot に割り当てた次のタスクなどが表示されます。
    - コードベースのドキュメントを更新する
    - ゲームを変更するアプリケーションプログラミングインターフェイス (API) を生成する
    - Web サイトにハイコントラストモードを追加する
3. 実行中のタスクを選択し、Copilot が行った作業を確認します。次のような操作が含まれることがあります。
    - リポジトリからコードをチェックアウトする
    - Copilot が作業する環境を作成する
    - モデルコンテキストプロトコル (MCP) サーバーをセットアップする
    - 割り当てられたタスクを完了するために、さまざまな手順を実行する

> [!NOTE]
> 表示される手順は、Copilot の作業状況や選択したアプローチによって異なります。

4. 右側に表示されるプルリクエストのペインも確認します。ここでは、追加の監視に使う PR と変更ファイルを確認できます。

## cloud agent に追加の指示を与える

現在実行中のタスクを確認できたので、ハイコントラストモードの作業中にライトモードの切り替えも追加するよう Copilot に依頼します。

1. ハイコントラストモードの追加に関するセッションを選択します。タイトルは Copilot が付けた名前や作業状況によって異なります。

    ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了して作業が始まるまで、数分間セッションを確認します。次のようなメッセージが表示されたら、作業が始まったことがわかります。
3. **Steer active session while Copilot is working** ダイアログに、次のプロンプトを入力します。

    ```plaintext
    ハイコントラストモードの作業とあわせて、ライトモードも追加してください。ユーザーが希望する表示モードを選べるスイッチも用意してください。
    ```

    ![エージェントページで、Steer active session while copilot is working ダイアログが強調表示された cloud agent タスクのスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを認識し、作業に取り入れることを確認します。

## Copilot の作業を待つ

前回と同様に、Copilot が更新されたタスクに取り組みます。メッセージを送信した時点で作業していた手順が完了すると、新しい依頼を作業に取り入れます。

今回も数分かかるため、これまでに学んだことや確認したことを振り返る時間にできます。

## まとめと次のステップ

この演習では、GitHub Copilot cloud agent のタスクを監視し、指示を与える中心的な場所である Copilot エージェントページを確認しました。このミッションコントロールでは、進行中と完了済みのタスクを追跡し、作業内容を確認し、進行中のタスクを方向付けて範囲を調整したり追加のガイダンスを提供したりできます。

次の概念を確認しました。

- ミッションコントロールとエージェントページを使って、cloud agent のタスクを監視しました。
- 進行中のセッションに追加の機能を依頼し、方向付けました。

Copilot がアクセシビリティ機能の作業を進めている間に、次は[Copilot が作成したプルリクエストを反復して改善します][next-lesson]。
